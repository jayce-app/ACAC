# Project photos

Drop completion photos here, then register each one in `src/data/projects.ts`.

## Steps

1. Add your image file to this folder (example: `arena-brenham.jpg`)
2. Open `src/data/projects.ts`
3. Copy an existing project entry and update:
   - `id` — unique slug
   - `title` — short job name
   - `category` — one of the listed categories
   - `location` — optional city
   - `blurb` — optional one-line description
   - `image` — `/projects/your-filename.jpg`

## Photo tips

- Prefer finished jobs (no ladders, buckets, or clutter)
- Landscape photos work best
- JPG or WebP, roughly 1600px wide is plenty
